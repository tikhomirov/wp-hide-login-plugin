# Исправление выхода из админки (Hide Login)

## Задание
На кастомном URL входа (`whl_page`) запрос `?action=logout` у залогиненного пользователя перенаправлялся в админку до загрузки `wp-login.php`, из‑за чего выход не выполнялся.

## План
1. Не выполнять ранний redirect для залогиненных, если в запросе задан `action` (в т.ч. `logout`).
2. Регрессионные unit-тесты для guard-логики; `php -l` по PHP-файлам.
3. Commit, push, PR (без merge/deploy).

## Код
Итоговый коммит с исправлением: см. SHA в сообщении PR / `git log` на ветке `cursor/fix-logout-redirect-3680`.

**Ограничение тестов:** полноценный интеграционный сценарий WordPress (cookies, `wp_logout()`, redirect после выхода) в CI не поднимается; проверена логика root cause и существующие PHP lint.
